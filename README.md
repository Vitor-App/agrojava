# AgroJava

Sistema Integrado do Agronegócio desenvolvido em Java básico para praticar arrays, matrizes, busca, acumulação e estruturas de repetição.

## Escopo inicial

O sistema terá três módulos principais:

1. Registro de chuva dos 7 dias da semana usando `double[7]`, com cálculo da média e identificação do dia mais chuvoso.
2. Mapeamento da umidade do solo em uma matriz `double[4][4]`, com alerta para talhões abaixo de 30%.
3. Menu interativo com cadastro de dados, exibição do mapa, relatório de alertas e saída.

A aplicação funcionará no terminal, usando somente `Scanner`, arrays, matrizes, `do-while` e `switch-case`.
