# Algoritmo do AgroJava

1. Iniciar o programa.
2. Criar um array para armazenar a chuva dos 7 dias.
3. Criar uma matriz 4x4 para armazenar a umidade dos talhões.
4. Mostrar o menu principal.
5. No cadastro, ler os 7 volumes de chuva e as 16 umidades.
6. Na opção de mapa, exibir a matriz 4x4 formatada.
7. No relatório, informar os talhões com umidade abaixo de 30%.
8. Repetir o menu até o usuário escolher sair.
9. Encerrar o programa.
